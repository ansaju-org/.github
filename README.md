# 👋 Welcome to ansaju project 
## 🎓 About ansaju
**ansaju** (short for _Anti Salah Jurusan_, which means *"no more wrong major"*) is a collaborative initiative to build a smart recommendation system that helps students choose the right college major based on their interests, abilities, and aspirations.
## 🚀 Our Mission
To empower students with the right tools and insights so they can make informed decisions about their future education paths — reducing regret and improving long-term academic satisfaction.
